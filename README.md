# BANK-MANAGEMENT
# Console-Based Bank Management System

## Project Overview
A modular Python-based Banking Application developed as part of the Programming coursework at VIT Bhopal University.

## Features
- Account Creation & Authentication
- Deposit & Withdrawal Operations
- Balance Inquiry & Transaction History
- Modular File Structure & Unit Testing

## Tech Stack
- **Language:** Python 3.x
- **Testing:** unittest framework

## Project Structure
- `main.py`: Entry point for application
- `banking_operations.py`: Core banking business logic
- `database.py`: Data storage & retrieval handlers
- `test_banking.py`: Unit tests

## How to Run
```bash
python main.py
