# Bank Management System

1. Problem Statement

The aim of this project is to 
make a simple Bank Management 
System using Python. It helps 
the user to perform basic
banking tasks like creating an 
account, depositing money, 
withdrawing money, and checking 
the account balance.

2. Scope of the Project

This project is used for basic
banking operations. It provides 
a simple menu where the user 
can select the required
operation. In the future, more 
features like transaction
history, login security, and 
database connectivity can be 
added.

3. Target Users

- Bank customers
- Students learning Python
- Beginners learning programming
- Users who need basic banking operations

4. High-Level Features

- Create a new account
- Deposit money
- Withdraw money
- Check account balance
- Simple menu-based system
- Easy to use
- Handles invalid choices
- Exit option
